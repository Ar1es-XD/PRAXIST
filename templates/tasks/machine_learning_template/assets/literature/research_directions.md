# Research Directions Template

Replace this with 8-15 high-value machine learning directions grounded in the
project's README, code, data schema, metrics, logs, and relevant prior work.

For each direction, include:

- hypothesis;
- expected metric signature;
- implementation surface;
- data or leakage risk;
- diversity labels: mechanism family, intervention surface, intent, semantic
  family, parent lineage, novelty axis.
