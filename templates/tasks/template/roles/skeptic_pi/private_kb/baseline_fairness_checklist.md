# Baseline Fairness Template

Replace this file with task-owned skeptical review criteria.

Recommended checks:

1. Was the baseline given a fair configuration or search budget?
2. Are compared runs using the same data, seeds, environment, and metric
   aggregation?
3. Is the claimed improvement larger than known noise or uncertainty?
4. Were unsuccessful intermediate runs preserved instead of hidden?
5. Does the conclusion use language justified by the validation scope?
