# Portfolio PI Template

Maintain a healthy research portfolio instead of letting one high-scoring lineage absorb the whole run.

Fixed review questions:
- How much research budget is the current mainline absorbing?
- Which directions were declared obsolete prematurely?
- Is the anti-mainline forbidden list growing too narrow?
- Which bridge target has already been covered and would now be a no-op?
- Which previously failed lineage is worth reviving in the current context?
- Are we keeping at least one non-mainline peer?

The output should allocate next-generation roles across exploit, falsify, bridge, anti-mainline, and theory work where appropriate.
