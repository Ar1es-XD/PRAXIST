# Glossary

This glossary gives short navigation definitions. The linked pages own the full
contracts.

| Term | Meaning | Canonical detail |
|---|---|---|
| Task project | External runnable research problem supplied to Praxist | [Task Projects](../guides/task-projects.md) |
| Template | Replaceable task-project scaffold or deterministic smoke fixture | [Examples And Templates](../guides/examples-and-templates.md) |
| Example | Complete runnable reference project with task-owned code, evidence, and tests | [Examples And Templates](../guides/examples-and-templates.md) |
| Peer | One research agent working within a generation | [Research Loop](../guides/research-loop-variant-generation-flow.md) |
| Generation | A cohort of peer work followed by a research-planning boundary | [Research Loop](../guides/research-loop-variant-generation-flow.md) |
| Finding | Structured report of observed evidence or a reusable research lesson | [Architecture](../concepts/architecture.md) |
| Validation signal | Compact, non-durable evidence retained for validation, repair, or diagnostic follow-up | [Architecture](../concepts/architecture.md) |
| Incubator | Task-defined durable lower-admission library for complete, credible candidates | [Flexibility Controls](../guides/research-loop-flexibility-controls.md) |
| Frontier | Durable task-defined promoted evidence used by planning and reporting | [Architecture](../concepts/architecture.md) |
| Gems | Compact selected research memory used when a task enables periodic reset | [Task Projects](../guides/task-projects.md) |
| Principal Investigator (PI) | Independent planning agent that proposes next-generation work from committed evidence | [Panel Topology Prompts](../concepts/panel_topology_prompts.md) |
| Chair | Planning agent that compares PI proposals and commits one coherent agenda | [Panel Topology Prompts](../concepts/panel_topology_prompts.md) |
| Deep Innovation Gate (DIG) | Deep-reasoning innovation process that compares candidate mechanisms before implementation | [Deep Innovation Gate](../guides/deep-innovation-gate.md) |
| Quality-Diversity (QD) | Allocation principle that preserves varied strong candidate plans | [Quality-Diversity Allocation](../guides/qdig-cohort-allocator.md) |
| Herfindahl-Hirschman Index (HHI) | Concentration measure used to diagnose whether planned or realized work collapsed into too few categories | [Quality-Diversity Allocation](../guides/qdig-cohort-allocator.md) |
| Task harness | Task-owned evaluator, baseline, prompts, roles, and evidence contracts | [Task Projects](../guides/task-projects.md) |
| Codex-native mode | Explicit Codex SDK route authenticated by a saved ChatGPT login | [Quickstart](../getting-started/quickstart.md) |
